### Industry Types
According to Market Research reports, the largest valued types of robots are industrial and service robots, making up 75.2% of all industry shares in 2025. 

Though these fields vary in many ways, computer vision is a fundamental part of these shares, with its dependent sales making up almost 4 billion (Fortune Business Insights).
### Computer Vision
Computer vision is used to describe the way a robot is able to visualize the environment around it. This is commonly done through LiDAR, camera, and/or radar. 

Once data is collected the robot uses a computer vision model or CVM. There are a variety of types, including Vision-Language Models (VLMs) like those seen in LLMs such as Google's Gemini. However, for basic automation tasks, object detection provides the needed info.
